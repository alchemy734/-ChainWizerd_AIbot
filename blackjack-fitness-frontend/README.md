# Blackjack Fitness — Frontend

A mobile-first fitness application frontend focused on guided home workouts, progress tracking, health metrics, reminders, and an adaptive fitness dashboard.

## MVP screens

- Welcome / onboarding
- Sign in / sign up
- Fitness profile: height, weight, goals, experience
- Home dashboard
- Workout library and workout detail
- Active workout session
- Progress and statistics
- Steps / activity summary
- Heart-rate summary (UI-ready for future device/camera integration)
- Profile and settings

## Frontend-first principle

This phase intentionally contains no real health-data integrations, trading code, wallet code, or backend dependency. API/device integrations will be added behind typed service interfaces later.

## Planned stack

- React + TypeScript
- Vite
- Responsive/mobile-first CSS
- Component-driven UI
- Local mock data for the prototype

## Run locally

```bash
npm install
npm run dev
```
